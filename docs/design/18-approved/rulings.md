# Rulings on the inventory's open points

The conductor's rulings, 2026-11-09. **They bind all three designs**, so the designs differ in
form, not function (Carl's decision 2). Carl sees this list at the gate and may override any of
them. Points marked **yours** are form: each design chooses and lists its choice in its notes.

| Point | Ruling |
|---|---|
| O-01 later screens | **Draw EL-15–EL-19 in full**, labelled "later". Decision 1 asks for the finished product. |
| O-02 exercise detail from the workout | **Yours**, but reachable from the exercise in the workout in at most two taps. |
| O-03 an added warm-up set's weight | **Q22's ladder**: bar × 10, 50 % × 5, 70 % × 3, 85 % × 1 of the first working set. A single added warm-up takes the next rung. |
| O-04 onboarding | **Three pages**: welcome, units (kg/lb, km/mi), body data (skippable). Permissions at first need (SH-08), not in onboarding. First-use hints: the dock, swipe to delete a set, the long press on Start. |
| O-05 the live run's largest number | **Distance by default; a tap cycles** the large number through distance, time, current pace and average pace. |
| O-06 running scope | **Draw it all**: the live map as a panel that swipes away, standard and satellite map types, save route, flyover replay. The map provider is a build question, not a design one. |
| O-07 minimising a run | **Yes**: a run minimises like a workout and gets a Live Activity (lock screen and Dynamic Island). |
| O-08 Start and Home on a rest or run day | **Run day**: today's bubble is the run. **Rest day**: Home says so and shows the next planned session; Start offers it as "next". |
| O-09 Home's content | **Today's card plus the week's numbers**, and a disabled Food card marked later. |
| O-10 export | **Format chosen on the screen**: Strive JSON (for the training log), CSV, GPX for runs. **Periods**: since last export (default), this week, this month, all, custom. |
| O-11 creating a programme | **Yours.** |
| O-12 a run day in Plan | **Types**: Easy, Long, Tempo, Intervals. **Target**: distance or time. The day card starts the run. |
| O-13 where gear lives | **You** (strive#52's title). Devices and apps live in Settings. |
| O-14 where the main lifts are picked | **Yours**, within two taps of Progress. |
| O-15 profile fields | Name, birth year, sex, height, body weight, a goal in one line. **Body weight feeds bodyweight exercises.** |
| O-16 run records | Longest distance, longest time, fastest 1 km, 5 km, 10 km and half marathon, most climb. |
| O-17 running in Progress | Km per week over 12 weeks, the long run per week, and the run records. |
| O-18 run detail in History | **History opens RU-05 for a run** and WO-24 for a workout. |
| O-19 a missing illustration | **Yours**, but drawn: no empty box. |
| O-20 drag down to minimise, swipe-delete motion | **Yours**, and drawn in the motion notes. |
| O-21 three or more in a superset | **Allowed**, lettered A, B, C … |
| O-22 activity types (later) | **One "Activity" bubble** that opens the list, last used first. Draw it as later. |
| O-23 template share format | **Text through the share sheet.** |
| O-24 a record from the last 30 days | **Opens the exercise's Records** (EX-08). |
| O-25 "sets done" in the header | **Without warm-up sets.** |
| O-26 how far designs 2 and 3 move the navigation | **The five places stay** (Home, Food, Start, Plan, You). **Their form and Start's placement are free**, as long as every feature is within two taps and today's workout within one. |

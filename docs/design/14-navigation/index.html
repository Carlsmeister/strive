Chosen navigation

Home is today, Plan is ahead, You is behind. Start, the round button in the middle, begins every workout and run. Plan becomes Coach once guidance from the Carlsmeister OS coach arrives through import (strive#7).

Main flows

  • Start a workout: Home › Start Push day (1), or Start › Empty workout or a template (2). Full screen until Finish.
  • Start a run: Start › Run (2). Full screen until End.
  • Look at history: You shows recent activities (1); All activities (2); Progress (1).
  • Export: You › Export (2), then what, period and format, then the share sheet.
  • Plan the week: Plan shows the week, the programme, templates and the library (1); edit a template (2).

Decided

  • Tabs: Home, Food, Start, Plan, You. Start is a round action button in the middle, as in the old app (Carl, 2026-10-20).
  • Templates and the library live in Plan, with the week plan and the programme. History and progress live in You, as in Strava.
  • Plan becomes Coach once guidance from the Carlsmeister OS coach arrives through import (strive#7). No second set of training rules in the app.
  • Workouts and runs run full screen, without the tab bar, until Finish or End.
  • The same navigation on iPhone and Android. Designed for iPhone first; Android gets the same structure.
  • The app follows the system language. English and Swedish at first; any other language falls back to English; more languages later, each one a new resource file (strive#3).
  • Header buttons such as search or community wait until they are needed.

Deviations from Apple's guidelines

Accepted for now, because Carl is the only user. Listed so they are cheap to fix if Strive is ever submitted to the App Store.

  • All options: the Food tab is empty until strive#9. Apple: tabs are never hidden or disabled; an empty tab is the nearest thing.
  • Chosen, C, D, E, F: Start is an action in the tab bar, a round floating button from Android's Material design. Apple: "Use a tab bar to support navigation, not to provide actions."

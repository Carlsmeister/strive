Strive strength

Sketches for the strength screens, one choice at a time, built from the components in 16-components. The content of every screen was decided first, in 47 questions on strive#17. Judge sizes on the phone: each sketch runs the full width of the screen there.

Choice 1: the set row in Active workout

Logging a set is what the app is for, so this is drawn first. Each sketch is Bänkpress with a warm-up set and one working set logged, set 2 up next, and set 3 to come. The app suggests 82,5 kg (↑) because last time reached the top of the range with RIR to spare. Tap ✓ to log set 2 and the rest timer starts; tap an RIR to add it. The counter shows the taps the set took. The fields open the keypad, which is the next choice, so here they only show their hints.

S1 · A row per set

Every set is the same row of joined tiles: badge, last time, weight, reps, ✓. RIR opens under the set you are on. Everything is visible at once; the ✓ sits at the right edge of each row.

Logged and coming sets are short lines. The set you are on opens into a card with big fields, RIR and one wide "Logga set" button. Fewer, bigger targets; the card moves down the list as you go.

S3 · A logging dock at the bottom

The sets are short lines; the one you are on is outlined. Its fields, RIR and "Logga set" sit in a glass dock at the bottom of the screen, under your thumb, whichever exercise you scroll to. The rest timer floats just above the dock.

Last set took – taps

Chosen: S3, a logging dock (Carl, 2026-10-23), refined below in choice 1b. S1 and S2 stay as the record of why.

Choice 1b: how the dock opens, and what a set costs

Chosen: D3, with a grabber (Carl, 2026-10-23). Each set has its own ✓ that logs the hint as it stands; tapping the set opens the dock for changes. The dock closes when you swipe it down by its grabber or tap outside it. There is no ✕. D1, D2 and D4 stay as the record of why.

Carl's rule: the dock is closed until you tap a set, and closes when you tap outside it or swipe it down. Four ways to keep that, at different costs. Tap a set to start. The fields open the keypad (choice 2 draws it properly); − and + step 2,5 kg or one rep. The counter counts every touch, keys included.

Choice 2: the keypad

Strive's own keypad (Q16), in the D3 dock. All three have the same keys: digits, the decimal comma, ⌫, Dölj, Skivor on the weight, − and + with the field's step, and Nästa, which goes weight → reps → rest. On the rest field Nästa becomes "Logga ›": it logs the set like Logga does, closes the dock and starts the rest. Tap a set, then its weight. Skivor shows the plates per side for now; the plate calculator is choice 3.

Decided

Every screen's content is decided in the grilling on strive#17, Q1–Q47. The rules every sketch follows: tokens only; components from 16; Strong is inspiration for functions, never for looks; teal only for what can be tapped or is selected; glass only on controls and overlays; one set logged in three taps at most.

Deviations from Apple's guidelines

Accepted for now, because Carl is the only user. Listed so they are cheap to fix if Strive is ever submitted to the App Store.

  • RIR 4 or more is chosen from a row of 4–10 that the 4+ segment opens in the dock; the segment then shows the value (Carl, 2026-10-24). An RIR of 4 or more therefore costs one tap more, and joins Q13's listed exceptions. Not a deviation; listed here so the cost is visible.
  • RIR segments are about 29 pt wide in the dock, because RIR shares its row with the rest time (Carl, 2026-10-24). Apple, Accessibility: a hit target of 44 × 44 pt by default, 28 × 28 pt at minimum. They stay 44 pt tall and above the minimum. The fix is RIR on a row of its own, full width, which squeezes the rest time again.

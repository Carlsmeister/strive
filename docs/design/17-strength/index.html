Strive strength

Sketches for the strength screens, one choice at a time, built from the components in 16-components. The content of every screen was decided first, in 47 questions on strive#17. Judge sizes on the phone: each sketch runs the full width of the screen there.

Choice 1: the set row in Active workout

Logging a set is what the app is for, so this is drawn first. Each sketch is Bänkpress with a warm-up set and one working set logged, set 2 up next, and set 3 to come. The app suggests 82,5 kg (↑) because last time reached the top of the range with RIR to spare. Tap ✓ to log set 2 and the rest timer starts; tap an RIR to add it. The counter shows the taps the set took. The fields open the keypad, which is the next choice, so here they only show their hints.

S1 · A row per set

Every set is the same row of joined tiles: badge, last time, weight, reps, ✓. RIR opens under the set you are on. Everything is visible at once; the ✓ sits at the right edge of each row.

Last set took – taps

S2 · The next set opens up

Logged and coming sets are short lines. The set you are on opens into a card with big fields, RIR and one wide "Logga set" button. Fewer, bigger targets; the card moves down the list as you go.

Last set took – taps

S3 · A logging dock at the bottom

The sets are short lines; the one you are on is outlined. Its fields, RIR and "Logga set" sit in a glass dock at the bottom of the screen, under your thumb, whichever exercise you scroll to. The rest timer floats just above the dock.

Last set took – taps

Chosen: S3, with a dock that closes (Carl, 2026-10-23). The dock is open by default and moves on to the next set after Logga. Pull it down with the grabber to close it; tap any set to open it on that set, and tap a logged set to correct it ("Spara ändring"). Three taps per set is counted with the dock open: closed, every set costs one tap more to open it. S1 and S2 stay as the record of why.

Decided

Every screen's content is decided in the grilling on strive#17, Q1–Q47. The rules every sketch follows: tokens only; components from 16; Strong is inspiration for functions, never for looks; teal only for what can be tapped or is selected; glass only on controls and overlays; one set logged in three taps at most.
